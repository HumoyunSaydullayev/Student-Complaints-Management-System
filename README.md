## 📌 Overview / Loyiha haqida

### English
A role-based university portal built with **Django** enabling university students to submit grievances, academic appeals, and administrative feedback directly to responsible university officials. Features a multi-role authorization hierarchy (Student, Department Officer, Rectorate/Administrator), complaint ticket tracking, status updates (Pending, In Review, Resolved), and automated audit logs.

### O‘zbekcha
Universitet talabalari va ma'muriyati o'rtasidagi munosabatlarni shaffoflashtirish uchun **Django** freymvorkida yaratilgan talabalar shikoyat va arizalari boshqaruv portali. Tizimda talaba, mas'ul shaxs (dekanat/kafedra) va bosh administrator rollari mavjud bo'lib, murojaatlarni yaratish, ularning ko'rib chiqilish holatini kuzatish va javob xatlarini yuborish imkoniyatini beradi.

## 🚀 Key Modules / Asosiy modullar

- 🧑‍🎓 **Student Dashboard:** Submit new appeals, attach evidence files, and monitor ticket resolution progress.
- 👨‍💼 **Department Officer Portal:** Review assigned departmental appeals, update processing status, and provide official responses.
- 👑 **Super Admin Dashboard:** University-wide analytics, department resolution speeds, and compliance statistics.

## 🛠️ Quickstart

1. Clone repository:
   ```bash
   git clone https://github.com/HumoyunSaydullayev/Student-Complaints-Management-System.git
   cd Student-Complaints-Management-System
   ```
2. Install dependencies:
   ```bash
   pip install django
   ```
3. Run migrations and launch:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
4. Access platform at `http://127.0.0.1:8000/`.
